## 1. 项目整体说明

### 1.1 系统定位与用途

本系统是**唐山中骏商业管理有限公司**的内部财务ERP系统，服务于财务共享服务中心的日常工作。系统以商场能耗管理（电费/水费）为核心，覆盖从清表录入、启用管理、月末结转、凭证生成到余额核对的完整业务闭环，同时集成积分数据管理、合同台账检查、权责收入表处理等功能模块。

**核心业务场景**：

| 业务领域 | 功能描述 |
|---------|---------|
| 商场电费管理 | 电表清表录入、启用状态管理、月末电费结转、凭证生成、余额核对、合同匹配检查、成本单价调整 |
| 商场水费管理 | 水表清表录入、启用状态管理、水费参数表管理、月末水费结转、凭证生成、水费余额查询 |
| 数据看板 | 积分数据可视化分析（趋势、类型分布、会员等级、预警、消耗分析） |
| 数据更新 | 一键自动化下载能耗系统数据、百购合同台账、积分列表（RPA自动化） |
| 权责收入表处理 | 从ERP下载权责收入表、宽表转长表、按费用名称拆分、四舍六入五成双处理 |
| 积分数据管理 | 积分列表自动下载与增量追加、SQLite数据库存储、数据查询与分析 |

### 1.2 技术架构概览

```
┌─────────────────────────────────────────────────────────────┐
│                    前端展示层（Streamlit Web）                  │
│  app.py (主应用, ~6400行)  │  app2.py (独立轻量版)            │
├─────────────────────────────────────────────────────────────┤
│                    业务逻辑层（Python）                        │
│  calc_status / generate_voucher / 结转计算 / 余额核对 / 模板转换  │
├─────────────────────────────────────────────────────────────┤
│                    数据处理层                                  │
│  Pandas / openpyxl / python-docx / xlrd / xlwt / xlutils     │
├─────────────────────────────────────────────────────────────┤
│                    数据存储层                                  │
│  Excel (.xlsx/.xls) │ SQLite (积分列表.db)                    │
├─────────────────────────────────────────────────────────────┤
│                    RPA自动化层（Playwright）                     │
│  能耗系统(gcwy.sce-icm.com) │ 积分系统(bk.sce-icm.com)        │
│  ERP系统(bgerp.sce-re.com)                                    │
└─────────────────────────────────────────────────────────────┘
```

**关键设计特点**：

- **单文件架构**：主应用 `app.py` 包含所有业务页面（约6400行），通过 `session_state` 实现页面导航和状态管理
- **RPA集成**：使用 Playwright 无头浏览器自动登录外部系统并下载数据，通过 `subprocess` 在主应用中调用独立RPA脚本
- **双格式存储**：积分数据同时支持 Excel (.xlsx) 和 SQLite (.db) 两种存储格式，优先使用 SQLite 以获得更高性能
- **后台任务管理**：积分列表更新采用单例模式的 `BackgroundTaskManager`，通过 `threading` 实现后台异步执行
- **缓存策略**：通过 `@st.cache_data(ttl=...)` 装饰器实现数据缓存，结合文件修改时间戳实现自动刷新

### 2.4 各页面功能详述

#### 2.4.1 页面1：能耗系统-电费

| 标签页 | 功能说明 | 数据来源 | 输出 |
|-------|---------|---------|------|
| 清表录入 | 录入电表进场/撤场清表记录。自动生成自建ID（格式：表号+品牌+申请日期），支持行选择自动填充表号/品牌/客户编号。提交后追加到 `能耗_电费数据.xlsx` 的 Sheet1 | 用户手动输入 | 更新 `能耗_电费数据.xlsx` Sheet1 |
| 启用明细 | 根据结账日期计算每个电表的启用状态。支持按状态、表号、品牌筛选。默认显示"启用中"和"本月启用"状态 | `能耗_电费数据.xlsx` Sheet1（清表记录） | 页面展示 + session_state 缓存 |
| 模板转换 | 上传充值结算记录(.xls/.xlsx)，通过多表merge转换为百购应收帐单导入模板和批量开票模板。支持下载两个模板文件 | 上传文件 + `能耗_电费数据.xlsx`（启用明细）+ `客户资料.xlsx` + `租赁合同台账_正铺.xlsx` + `租赁合同台账_多经.xlsx` + `开票信息.xlsx` | 生成应收帐单导入.xls + 批量开票-导入开票模板.xlsx |
| 余额预警 | 监控租户余额和剩余天数。支持"且/或"逻辑预警条件，可一键更新租户概览数据 | `能耗_电费数据.xlsx`（启用明细）+ `租户概览.xls` | 页面展示预警列表 |

#### 2.4.2 页面2：能耗系统-水费

| 标签页 | 功能说明 | 数据来源 | 输出 |
|-------|---------|---------|------|

| 水费结转 | 水费月末结转（税率9%），计算用水量/收入/成本，生成凭证模板，支持存档 | `能耗_水费数据.xlsx`（清表记录+参数表+表底）+ `凭证模板.xlsx` | 结转明细.xlsx + 凭证模板.xlsx + 更新结转留存 |

#### 2.4.3 页面3：月末结转-电费

| 标签页 | 功能说明 | 数据来源 | 输出 |
|-------|---------|---------|------|
| 电费结转 | 核心结转逻辑：筛选有效电表 → 计算用电量 → 查参数表获取单价 → 计算收入/成本 → 生成凭证。支持存档到 `结转留存.xlsx` | `能耗_电费数据.xlsx`（清表记录+参数表+表底）+ `凭证模板.xlsx` | 结转明细展示 + 凭证模板下载 + 存档 |

## 5. 核心业务逻辑详解

### 5.1 电表状态计算逻辑（calc_status）

该函数在 `app.py` 中被定义 **7次**（分别用于电费启用明细、水费启用明细、月末结转、余额核对报告、合同检查等场景），逻辑完全一致。

**函数签名**：`def calc_status(row)`

**输入参数**：

| 参数 | 来源 | 说明 |
|-----|------|------|
| row["进场日期"] | 同一自建ID最近进场清表的申请日期(datetime) | 可为 NaT |
| row["撤场日期"] | 同一自建ID最近撤场清表的申请日期(datetime) | 可为 NaT |
| settlement | 用户选择的结账日期(pd.Timestamp) | 外部变量 |
| month_start | 结账日期当月第一天(pd.Timestamp) | `settlement.replace(day=1)` |

**判断优先级（从上到下依次判断，命中即返回）**：

| 序号 | 条件 | 返回值 | 含义 |
|-----|------|-------|------|
| 1 | 进场日期为空 (NaT) | `"无进场记录"` | 从未进场 |
| 2 | 进场日期 > 结账日期 | `"未启用"` | 已登记但尚未到启用时间 |
| 3 | 进场日期 >= 月初 且 撤场日期 <= 结账日期（本月进场且本月撤场） | `"本月调整"` | 当月进出 |
| 4 | 进场日期 < 月初 且 月初 <= 撤场日期 <= 结账日期（之前进场且本月撤场） | `"本月终止"` | 本月终止 |
| 5 | 进场日期 < 月初 且 撤场日期 < 月初（之前进场且之前撤场） | `"已终止"` | 已终止 |
| 6 | 进场日期 >= 月初 且 (撤场日期为空 或 撤场日期 > 结账日期)（本月进场且未撤场） | `"本月启用"` | 本月新启用 |
| 7 | 进场日期 < 月初 且 (撤场日期为空 或 撤场日期 > 结账日期)（之前进场且未撤场） | `"启用中"` | 正常使用中 |
| 8 | 以上均不匹配 | `"异常状态"` | 兜底异常 |

**月末结转有效状态**：仅"启用中"、"本月启用"、"本月终止"、"本月调整"四种状态参与结转计算。

### 5.2 电费结转计算逻辑

**步骤详解**：

```
1. 筛选有效电表
   └─ 从启用明细中筛选状态为"启用中/本月启用/本月终止/本月调整"的电表

2. 计算结算周期
   ├─ 开始日期 = max(进场日期, 月初第一天)
   └─ 结束日期 = min(撤场日期, 次月第一天)  [有撤场日期时]
              或 结账日期 + 1天              [无撤场日期时]

3. 匹配表底数据
   ├─ 从"表底"工作表中按表号+日期匹配开始表底
   └─ 从"表底"工作表中按表号+日期匹配结束表底

4. 计算用电量
   └─ 用电量 = 结束表底 - 开始表底

5. 查询单价
   ├─ 先查参数表中该品牌的"特殊单价"
   └─ 若无特殊单价，使用"普通单价"
   └─ 收入单价和成本单价分别查询

6. 计算金额（税率13%）
   ├─ 收入_含税 = 用电量 x 收入单价
   ├─ 收入_不含税 = 收入_含税 / 1.13
   ├─ 成本_含税 = 用电量 x 成本单价
   └─ 成本_不含税 = 成本_含税 / 1.13

7. 添加合计行
   └─ 对用电量、收入_含税、收入_不含税、成本_含税、成本_不含税求和
   └─ 单价字段不汇总（置空）
```

### 5.3 水费结转计算逻辑

与电费结转逻辑结构相同，差异点：

| 差异项 | 电费 | 水费 |
|-------|------|------|
| 税率 | 13%（/1.13） | 9%（/1.09） |
| 数据文件 | `能耗_电费数据.xlsx` | `能耗_水费数据.xlsx` |
| 存档位置 | `结转留存.xlsx`（独立文件） | `能耗_水费数据.xlsx` 的"结转留存"工作表 |
| 凭证科目 | 2241060301/6051050101/6402020101 | 2241060302/6051050102/6402020102 |

### 5.4 余额核对计算逻辑

**核心公式**：

```
新增差异 = 金蝶测试金额_含税 - 能耗系统余额_汇总 + 未到账金额_含税 - 前期差异
```

**各字段计算链**：

```
金蝶期末余额
    └─ 来自：辅助核算项目余额表.xlsx

本月结转_不含税
    └─ 来自：当期电费结转数据中收入_不含税的汇总

金蝶测试金额_不含税 = 金蝶期末余额 - 本月结转_不含税
金蝶测试金额_含税 = 金蝶测试金额_不含税 x 1.13

能耗系统余额_汇总
    └─ 来自：能耗余额.xls，按客户汇总

未到账金额_含税
    └─ 来自：财务订单.xls，筛选未到账记录汇总

前期差异
    └─ 来自：上期余额核对结果中的差异金额
```

## 9. 常见问题与报错解决方案

### 9.1 文件相关错误

| 错误现象 | 可能原因 | 解决方案 |
|---------|---------|---------|
| `主数据文件不存在：xxx/能耗_电费数据.xlsx` | `财务共享资料/9-数据库/` 目录下缺少数据文件 | 手动创建 `财务共享资料` 目录结构，或从备份恢复数据文件 |
| `凭证模板文件不存在：xxx/凭证模板.xlsx` | `财务共享资料/0-模板/` 目录下缺少模板文件 | 将凭证模板文件放置到 `0-模板` 目录 |
| `ERROR:无法删除旧文件 '财务订单.xls'` | 文件被Excel或其他程序占用 | 关闭所有Excel窗口，脚本会自动尝试 `taskkill /F /IM EXCEL.EXE` |
| `数据库读取失败，尝试使用Excel` | SQLite数据库文件损坏或被占用 | 检查 `积分列表.db` 文件状态，必要时从Excel备份恢复 |

### 9.2 RPA相关错误

| 错误现象 | 可能原因 | 解决方案 |
|---------|---------|---------|
| `下载超时（60秒）` / `下载超时（120秒）` | 网络延迟或目标系统响应慢 | 检查网络连接，确认目标系统可访问 |
| `下载失败：FAIL: ...` | 登录失败或页面结构变化 | 确认账号密码正确，检查目标系统是否有更新 |
| `脚本不存在：xxx.py` | RPA脚本文件缺失 | 确保所有 `.py` 脚本文件与 `app.py` 在同一目录 |
| `操作超时（10分钟）` | 积分列表下载等待时间过长（等待导出需180秒） | 正常现象，积分导出需要等待后台生成，请耐心等待 |

### 9.3 数据相关错误

| 错误现象 | 可能原因 | 解决方案 |
|---------|---------|---------|
| `暂无清表数据，请先添加记录` | 清表记录为空 | 先在"清表录入"中添加进场/撤场记录 |
| `下载的表底文件列数不足4列` | 下载的表底文件格式异常 | 手动检查 `能耗表底.xls` 文件内容 |
| `缺少列：['xxx']` | 结转留存数据缺少必要字段 | 检查 `结转留存.xlsx` 的列名是否完整 |
| `请先安装 python-docx 库` | 缺少 python-docx 依赖 | 执行 `pip install python-docx` |

### 9.4 Playwright相关

| 错误现象 | 可能原因 | 解决方案 |
|---------|---------|---------|
| `playwright` 模块导入失败 | Playwright未安装或浏览器驱动缺失 | 执行 `pip install playwright` 后运行 `playwright install chromium` |
| 浏览器启动失败 | Chromium浏览器未正确安装 | 运行 `python -m playwright install chromium` |

### 9.5 环境配置

| 错误现象 | 可能原因 | 解决方案 |
|---------|---------|---------|
| 端口8501/8502被占用 | 其他Streamlit实例正在运行 | 关闭其他实例或更换端口 |
| `ModuleNotFoundError: No module named 'streamlit'` | 虚拟环境未激活或依赖未安装 | 激活 `.venv` 虚拟环境后执行 `pip install -r requirements.txt` |
